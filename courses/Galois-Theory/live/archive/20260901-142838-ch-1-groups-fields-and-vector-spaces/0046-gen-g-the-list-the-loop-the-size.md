title: The subgroup one element makes — the list, the loop, the size

One piece of machinery, then we open 1.7.

For $g \in G$, write $\gen{g}$ for the set of all powers of $g$:
$$\dots,\ g^{-2},\ g^{-1},\ e,\ g,\ g^2,\ g^3,\ \dots$$
It is a subgroup — the smallest one containing $g$.

The **order** of $g$ is the least $k > 0$ with $g^k = e$, if such a $k$ exists. When it does,
$$\gen{g} = \{e,\ g,\ g^2,\ \dots,\ g^{k-1}\},$$
and those $k$ entries are distinct, so $\lvert\gen{g}\rvert$ is exactly the order of $g$. Once you hit $e$ the cycle resets; nothing new appears afterwards.

You did this already with $g = (1\,2\,3\,4)$ in $S_4$: powers gave $(1\,3)(2\,4)$, then $(1\,4\,3\,2)$, then $e$, and you stopped. Order $4$, so $\lvert\gen{g}\rvert = 4$. And since $\lvert S_4\rvert = 24 \neq 4$, that one element does **not** generate $S_4$.

That is the sentence 1.7 hangs on. *" $G$ is generated by $g$ "* means $\gen{g} = G$, which for finite $G$ means nothing more than: the order of $g$ equals $\lvert G\rvert$.

**Your turn — one small one.**

Let $\ZZ_6 = \{0,1,2,3,4,5\}$ under addition mod $6$. It is written additively, so "powers of $g$" means
$$0,\ \ g,\ \ g+g,\ \ g+g+g,\ \ \dots$$
List $\gen{2}$: keep adding $2$ until you come back to $0$.
