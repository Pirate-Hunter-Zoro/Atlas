Your question has a short answer: that statement is false, and the fact that it is false is exactly the lever you were looking for. If {l₂} spans L over k, then every element of L equals c·l₂ for some c in k. Your l₁ is in L. So there is a c in k with c·l₂ = l₁, always. Nothing to prove there, nothing to rule out — you are meant to use it.

One naming repair before anything else. You wrote k for the field and k for the scalar in "k l₂ ≠ l₁". Call the scalar c instead. Two different things under one name is how a page stops being readable.

So the contradiction does not come from an element of L you cannot reach. Every element is reachable — that is what "spans" says. It comes from what spanning forces on l₂ itself.

Here is the tiny step, and one equation answers it. There is an element of L you already know lies in k, for free: 1. Apply spanning to it. Write the equation that says 1 is reachable from the basis {l₂}.

what this uses:
- [L:k] = 1: one vector of L spans all of L, with coefficients from k. That is your own sentence, and it is right.
- spans: every element of L is c·l₂ for a single c taken from k.
- basis: a spanning set with nothing redundant in it.
- l₂: the one basis vector, a fixed element of L.
- c: a coefficient, an element of k.
- 1 ∈ k and 1 ∈ L: k is a field sitting inside L, so they share the same 1.
- where this is going: L = k, which is what row one of your table needs.
