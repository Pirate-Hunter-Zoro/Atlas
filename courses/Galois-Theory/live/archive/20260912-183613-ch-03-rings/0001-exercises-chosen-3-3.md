**Exercise 3.3.** *Show that an integral domain with a finite number of elements is always a field.*

- *Ring:* commutative, with $1 \neq 0$.
- *Integral domain:* a ring in which $rs = 0$ forces $r = 0$ or $s = 0$.
- *Unit:* $q$ with $qq^{-1} = 1$ for some $q^{-1} \in R$.
- *Field:* a ring in which every non-zero element is a unit.

Not yet. First, one thing by hand.

**Your move.** Take $a = 2$. Write out the full list of products $2x$ as $x$ runs over every element:

- in $\mathbb{Z}_6$, for $x = 0,1,2,3,4,5$;
- in $\mathbb{Z}_5$, for $x = 0,1,2,3,4$.

Then answer two things about *those lists*: in which one does $1$ appear, and in $\mathbb{Z}_6$ name a non-zero $x$ with $2x = 0$.
