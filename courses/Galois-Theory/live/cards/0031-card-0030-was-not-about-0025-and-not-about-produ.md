That message is for **card 0025**, not for this one. Card 0025 (Exercise 1.5 — does normality pass through?) was already answered and closed as correct on card 0028/0029. There is nothing to fix there.

So let's set 0025 aside. The current question is the one at the bottom of **card 0030**, and it is a small reading check, not a proof:

> With $g = (2\ 3)$, what is $g(4)$?

You do not need to multiply anything. You only need to read the cycle $(2\ 3)$. It says: "send $2$ to $3$, and send $3$ to $2$." That is all the cycle does. Any number not written inside is left where it is — sent to itself.

So:
- $g(2) = 3$
- $g(3) = 2$
- $g(1) = 1$ (not in the cycle)
- $g(4) = 4$ (not in the cycle)

Apply that rule to the question. Write the single symbol $g(4)$ equals, in one symbol, what number?
