# Longtable assistants

Read `RULES.md`, `TUTOR.md`, and `QUESTS.md` before acting. Follow Atlas's root
constraints. Inside the board, also follow `board/TEACHING.md`.

This is an owner-coded learning project. A request to create these documents is not
permission to implement the game. Coach the next unfamiliar operation in plain English,
then wait. Explicit implementation requests authorize the requested work.

Keep persistent lesson state in `TUTOR.md` through `board memo`. Do not create a second
progress log. Check actual files before claiming a feature or skill is complete.

The product is offline first and iPad first. Treat every screen as if a finger and a Pencil
are the only input, and as if the Wi-Fi drops during a fight. Use only the SRD 5.1 and the
owner's own content.
