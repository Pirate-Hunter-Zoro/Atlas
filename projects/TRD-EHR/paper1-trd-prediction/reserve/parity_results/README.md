# Parity results, tracked

The numeric artifacts behind `../matched_input_parity.md`, copied here because
this is the only place they are under version control. `TRD-EHR/results/` is
gitignored in its own repository, and the `results` symlink at the root of this
one is gitignored here too, so a commit in either repo otherwise carries the
prose and none of the numbers.

Everything here is a copy. The originals live at
`TRD-EHR/results/review/parity/`, mirrored from
`ARTIFACTS_DIR/review/parity/`, and are regenerated by
`python -m scripts.pipeline.review.parity.summarize`. If a number here
disagrees with one there, there is right and these are stale.

| File | Origin | What it holds |
| --- | --- | --- |
| `parity_summary.csv` | `parity_summary.csv` | every contrast, both AUCs, the paired delta and interval |
| `parity_summary.json` | `parity_summary.json` | the same, plus the KNN ROC scores by arm and the decision |
| `feature_arm_deltas.csv` | `feature_arm_deltas.csv` | the feature arm against the published feature arm |
| `feature_vitals_metrics.json` | `feature_vitals/metrics.json` | the feature arm's full metric block and selected hyperparameters |
| `<arm>_deltas.csv` | `<arm>_deltas.csv` | each narrative arm against the published embedded arm |
| `<arm>_metrics.json` | `<arm>/metrics.json` | each narrative arm's metric block and selected hyperparameters |
| `<arm>_knn_results.json` | `<arm>/knn_results.json` | nearest and random retrieval ROC per weighting |
| `<arm>_knn_summary.csv` | `<arm>/summary.csv` | the same arms' full neighbour metric block |

## What is deliberately not here

Per-patient held-out probabilities (`test_predictions.parquet`, ~420 KB per
arm), the neighbour arm's per-patient risks (`summary_predictions.csv`, ~2.2 MB
per arm), the plot trees (~19 MB per narrative arm), the embedding databases and
the trained model objects. Those stay under `ARTIFACTS_DIR` and its mirror. What
is tracked is what a reader of the reserve document would need to check a
quoted number, not what a re-analysis would need to recompute one.

## Currency

Complete as of 2026-08-30: all three arms have reported and
`parity_summary.json` carries the decision, which is that no head-to-head
contrast on matched inputs moves discrimination beyond sampling noise. Re-copy
every file here if `summarize` is ever re-run.
